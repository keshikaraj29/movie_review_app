# 🎬 Movie Review Application

A full-stack web application that allows users to explore movies, write reviews, and rate them. It helps users make informed decisions and connect with other movie enthusiasts.

---

## 🚀 Features

- User Signup & Login (JWT Authentication)
- Browse and search movies
- Add, edit, and delete reviews
- Rate movies
- Responsive UI

---

## 🛠️ Tech Stack

Frontend:
- HTML
- CSS
- JavaScript
- Bootstrap

Backend:
- Node.js
- Express.js

Database:
- MongoDB (Mongoose)

---

## ⚙️ Setup

Clone the repository:
git clone https://github.com/your-username/movie-review-app.git
cd movie-review-app

Install dependencies:
npm install

Create a `.env` file and add:
PORT=8000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret

Run the application:
npm start

Open in browser:
http://localhost:8000

---

## 📂 Key Modules

- Auth: User login and signup
- Movies: Fetch and display movies
- Reviews: Create, update, delete reviews

---

## ⚠️ Limitations

- Reviews are subjective
- Possible spam or fake reviews
- Requires internet connection
